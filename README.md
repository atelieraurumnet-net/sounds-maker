# OTO — ブラウザ・シンセサイザー

Web Audio APIで電子音を鳴らし、画面上のピアノ鍵盤・PCキーボード・Web MIDIで演奏できる、依存ライブラリ不要のWebアプリです。

## 起動方法

`index.html`をブラウザで開くか、リポジトリのルートで簡易HTTPサーバーを起動します。

```sh
python3 -m http.server 8000
```

`http://localhost:8000`を開き、鍵盤をクリックして音を有効にしてください。MIDI機器の接続は、Web MIDI対応ブラウザ（ChromeまたはEdge）のHTTPSまたはlocalhost環境で利用できます。

## 操作

- 画面の鍵盤をクリック／タッチして演奏
- PCキーボードの`Z`〜`M`と`Q`〜`U`で2オクターブを演奏
- `−`／`+`で鍵盤の音域を変更
- 波形、音量、デチューンを調整
- 「MIDIを接続」からMIDIキーボードを接続
